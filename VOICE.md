# Slinky — voice

To *slink*: to move quietly so nobody notices. Secrets slip in where they're needed and slip back out. Three words: **quiet, sly, kept.** Same dry, warm register as Dinky and Binky. Slinky is the actor. No exclamation points. One-liners.

| Moment | Line |
|---|---|
| Tagline | Slinky keeps secrets out of your files. |
| Site hero | Keys under the doormat? Meet Slinky. |
| Empty state | Nothing to hide. Yet. |
| Detection | Looks like a Stripe live key. |
| After an import | Tucked away 9. The .env can go. |
| Agent needs a key | Claude Code needs RESEND_API_KEY. Paste it here, not in the chat. |
| Copy | Copied. Clears in 60s. |
| Denied | Denied. Nothing slipped out. |
| Locked | Locked. Touch ID to peek. |
| Low codes | 3 codes left. Time for fresh ones. |
| Wallet seed | That looks like a wallet seed. It belongs on paper, not on a computer an agent can reach. |

Avoid: "military-grade", AES jargon in the UI, "credentials", "workflow", exclamation points, fear-selling. Buttons name the consequence ("Move to Trash" / "Keep It for Now").
