Slinky · layout concepts

Six ways to hold a secret

Six simple layouts, each built from what people complain about in 1Password, Bitwarden, Apple Passwords and the new crop of developer-secret apps. Glass on the chrome, opaque paper under the values, and every mock is clickable. All keys shown are fake.

What competitor users keep saying

Six complaints worth designing against

Very common

"It doesn't feel like a Mac app"

1Password 8's non-native-feel thread runs past 127 replies. Bitwarden can take minutes to load on Tahoe. 1Password · Bitwarden

Common

Too many clicks to copy

Bitwarden's 2026 redesigns made only titles clickable, added spacing and dropped copy shortcuts. People asked for a revert. forum

Common

Quick Access copies the wrong thing

Search opens the previously viewed item, so people paste the wrong password without noticing. 1Password

Five years running

Recovery codes have no home

Six-plus threads ask for masked codes, one per row, mark-as-used and a date. People dump them into notes instead. 1Password

Growing

API keys forced into password shapes

"Username" and "Credential" labels on API keys confuse people, and there's no environment, expiry or rotation. 1Password

Very common

Glass you can't read

Tahoe's light mode bleaches edges away, and selection highlights vanish. macOS 27 added a transparency slider and put sidebars back edge-to-edge. Eclectic Light · Six Colors

Rules for our glass

Translucent where it helps, solid where you read

  1. Glass only on chrome: sidebar, toolbar, quick panel, approval cards, inspector.
  2. Values sit on opaque paper, in monospace, at 4.5:1 contrast or better.
  3. No whiteout: hairline edges, soft shadows, and a slightly cooler paper.
  4. The accent appears once per view, on the primary action.
  5. System split views, so sidebars follow macOS 26 and 27 on their own.
  6. Test both ends of the transparency slider, Reduce Transparency and an LCD.
A

The .env, without the file

The main window looks like the file you already know: line numbers, # comments, KEY = value. Only the values are masked, and every line knows which environments it's in.

Fixes

  • No more API keys forced into password shapes: a variable is a KEY and a value, the way you write it.
  • Drift is visible: lines from .env.example that Slinky lacks show up empty, with Ask right there.
  • Environments as columns, Infisical-style, so "missing in Production" is a hollow dot, not a surprise deploy.
  • The inspector floats over the paper instead of adding a third column.

Borrowed from

Infisical's environment matrix, Railway's .env.example suggestions and sealed variables, Vercel's write-only secrets, and code editors' gutters.
B

The Shelf

For everything that isn't a project: recovery codes, recovery keys, personal tokens, the router password. Cards on a shelf, each shaped like what it holds.

Fixes

  • Recovery codes finally get a real shape: a grid of chips, cross off as you use them, a count, a date.
  • "Store this somewhere safe" has a home that isn't a notes field, with Apple's own hover-to-reveal.

C

The Palette

Quick Access that can't copy the wrong thing: the selected item is always previewed, big, before you press Return. Flip to Tuck Away and one paste goes to the right place.

Fixes

  • Wrong-item copies: the preview pane always shows exactly what Return will copy, with "Return copies this" spelled out.
  • Capture friction: Tuck Away reads a paste and suggests Kept, Key or a project variable. Derek's recovery key, personal token and env secret each land right.
  • No hotkey clash with macOS 27's Visual Intelligence or 1Password's new ⌥⌘\.

Borrowed from

Raycast's ↵ / ⌘↵ / ⌘K model, Spotlight's look, and 1Password's Quick Access, minus its wrong-item bug.
D

Receipts

When agents ask, approval cards stack in the corner like CleanShot thumbnails. Answer one and it folds into a receipt on that key's timeline. Every use of every key, in plain words.

Try: Simulate requests · Allow or Deny each · flip the Agents switch in the menu bar

Fixes

  • Secretive's new pending-requests window can hide behind other windows, and 1Password's mounted .env can't tell processes apart. Slinky's cards are always frontmost and name the asker, the folder, the key and the agent's stated reason (marked unverified).
  • Several agents at once don't pile up modal dialogs; they queue as a stack you can clear in seconds.
  • "Who used this key, when?" has one answer per key, which is also the rotation checklist after a leak.
  • A menu bar switch (or Control Center control) pauses all agent access instantly.

Borrowed from

Secretive's notify-on-every-use, CleanShot's floating thumbnails, and Tahoe's Control Center controls.
E

The Rising Shelf

A different Quick Access: on ⌥⌘K a frosted shelf rises from the bottom of the screen, like a drawer sliding out. Pill tabs with counts, big cards you can read at a glance, and a slot at the front that catches whatever you paste.

Try: click the shelf, then ←→ to move, Return to copy, 1–5 to switch tabs · or click tabs and cards

Why it might beat C

  • Cards are bigger than rows, so it's harder to grab the wrong key, the same problem C solves with its preview.
  • It never covers the window you're working in; it lives along the bottom edge, near the Dock.
  • The paste slot makes "store this somewhere safe" a single gesture.
  • Requests get a tab with a count, so agent asks are never buried.

Borrowed from

Supaste's bottom-edge clipboard shelf, macOS's own Dock, and Stage Manager's sense of things sliding in and out.
F

The menu bar, as a stack of glass

Fixes

  • A plain menu hides state behind words. Cards show it: the lock timer and the clipboard timer actually tick.
  • An agent request can be answered right from the menu bar, without opening any window.
  • macOS 27 can hide menu bar extras in an overflow, so the widget (G) and a Control Center control carry the same status.

Borrowed from

DisplayBuddy's stacked translucent control cards, Cooldock's live tiles, and Control Center's own modules.

Recommendation

Use them together, each where it belongs

A is the main window

Projects in the sidebar open as .env views. It's where developers live.

B is the Library

Recovery Codes and Kept in the same window open as the Shelf, so non-project things get their own shape.

C is Quick Access, E is the challenger

⌥⌘K opens the Palette by default. The Rising Shelf (E) is worth a real side-by-side once the app runs; it may feel better for people who think in cards. Tuck Away is the default when the clipboard holds something new.

D and F are how agents meet you

Approval cards in the corner, Receipts in the sidebar, and the menu bar as a stack of live glass cards (F) with the Agents switch. The widget (G) comes in v1.x.
